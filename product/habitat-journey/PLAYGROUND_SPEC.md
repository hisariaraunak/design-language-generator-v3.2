# Habitat Journey Prototype Specification

The playground demonstrates the canonical flow on a phone-sized web surface: Today → Log → Food Details → XP receipt → Habitat → Friend Unlock → Progress.

## Coverage

- Navigation, button, card, input, filter, progress, chart, dialog, loading, empty, offline, and error patterns.
- Nutrition values remain readable independently of Habitat XP.
- Labels, focus order, screen reader status announcements, keyboard activation, and 44 px touch targets.
- Light theme semantic tokens and accessible contrast.
- Typography uses defined type sizes, line heights, and dynamic type-compatible rem units.
- Icon system uses consistent 24 px size, rounded stroke intent, selected state, and visible text label.
- Data visualization pairs color with values, axis labels, units, and textual summaries.

The browser prototype is design evidence, not production runtime or device verification.
