# Cross-Platform Parity

The production targets are iOS and Android. The web implementation is an interaction prototype and documentation surface.

## Must match

- Canonical token role, component state, event meaning, content hierarchy, data units, nutrition calculations, safety copy, and accessibility outcome.
- Today, Log, Food Details, Habitat, Friend Unlock, and Progress information architecture.
- Reduced motion, labeled charts, 44 px touch targets, and non-color state cues.

## Platform-native divergence

- iOS uses native navigation bars, sheets, Dynamic Type, and VoiceOver semantics.
- Android uses Material-compatible system navigation, Compose semantics, and TalkBack behavior.
- Web uses semantic HTML, keyboard focus, and responsive reflow only for design demonstration.

Any visual or behavioral divergence requires a rationale, screenshots, and mapping back to the canonical token or component contract.
