# Habitat Journey Components

The library separates domain-neutral controls from nutrition and habitat patterns.

## Foundations and controls

- Button, icon button, text input, search input, segmented control, filter chip, card, progress bar, dialog, bottom sheet, toast, inline error, loading skeleton, and empty state.
- Navigation includes top bar, five-item app tab bar, and platform-native back behavior.
- Feedback covers loading, success, empty, offline, partial, and recoverable error states.

## Nutrition patterns

- Calorie ring, macro card, meal row, food row, serving stepper, nutrition summary, and meal review.
- Every value includes its unit and a visible label. Charts and progress never depend on color alone.

## Habitat patterns

- Companion coach card, daily quest card, habitat stage, friend avatar, XP receipt, and unlock celebration.
- Habitat patterns cannot replace, obscure, or modify nutrition information.

## Accessibility

All interactive components support a 44 px target, screen-reader names and states, visible focus, dynamic type, high contrast, and reduced motion. Illustration descriptions convey meaning without describing decorative scenery unnecessarily.
