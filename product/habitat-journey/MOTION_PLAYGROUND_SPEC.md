# Motion Playground Specification

- Navigation duration: 220 ms ease-out.
- Progress duration: 450 ms ease-out after confirmed data changes.
- Reward duration: 800 ms, interruptible and skippable.
- Reduced motion: replace movement and scale with an immediate static state and polite status announcement.
- No infinite animation, parallax, or forced waiting.
- Focus moves only when navigation or a modal transition requires it.
