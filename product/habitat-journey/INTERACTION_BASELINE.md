# Locked Interaction Baseline

- Navigation: five persistent destinations—Today, Log, Progress, Habitat, Profile—with platform-native back behavior.
- Focus and keyboard: logical document order, visible focus, no keyboard traps, all actions keyboard-equivalent where applicable.
- Gestures: gestures are enhancements; every gesture has a labeled control alternative.
- Validation: errors appear inline, explain recovery, and preserve entered data.
- Overlays: bottom sheets and dialogs trap focus, announce titles, and support explicit dismissal.
- Selection: selected meal, unit, and filter state is visible in text and accessibility state.
- Destructive actions: deletion of saved data requires risk-based confirmation.
- Async states: loading, empty, offline, partial, success, and recoverable error states are defined.
- Rewards: XP is shown only after health data is confirmed; celebrations are skippable and reduced-motion safe.
