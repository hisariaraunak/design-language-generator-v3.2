# Contributing

## Change types
Classify each change as additive, corrective, deprecating or breaking. Identify affected tokens, components, screens, implementations and tests.

## Required review
Name design and engineering owners. Record approvers, rationale and linked evidence. Changes affecting locked baselines require explicit baseline revision.

## Validation
Regenerate all downstream artifacts marked stale. Protected validations must be recomputed from fresh evidence. No manual PASS overrides.

## Release impact
State SemVer impact, migration requirement, deprecation schedule and rollback path.
